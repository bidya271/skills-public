# Web Design Guidelines Auditor

Automated UI and UX code auditing against modern Web Interface Guidelines accessibility standards and responsive frontend ergonomics.

You can buy the full skill pack for the price of a coffee directly on the listing page.

## The Problem

Frontend code frequently ships with subtle accessibility violations and UX bugs that degrade user trust.

Missing focus rings poor keyboard navigation unstyled touch targets layout shifts on mobile devices and unhandled loading states slip through pull request reviews.

Manual design audits take days and standard linters only catch syntax errors rather than human ergonomic and accessibility failures.

## The Solution

This skill conducts automated deep-dive audits of your frontend files against comprehensive Web Interface Guidelines.

It checks your React Vue HTML and CSS components against accessibility rules responsive design principles interactive state handling and semantic DOM best practices.

## How This Skill Solves It

* **Terse File:Line Reporting:** Delivers concise actionable findings linked directly to the exact file and line number.
* **WCAG Accessibility Verification:** Catches missing ARIA tags poor color contrast and broken keyboard focus rings.
* **Touch and Keyboard Ergonomics:** Enforces 44px minimum tap targets and intuitive tab order navigation.
* **Loading and Empty State Audits:** Checks that skeleton loaders error states and asynchronous fallbacks are cleanly rendered.
