# Codebase Knowledge Base Generator

Generate systematic architecture diagrams concept maps and module documentation templates for single projects and monorepo codebases.

You can buy the full skill pack for the price of a coffee directly on the listing page.

## The Problem

Most software codebases have zero useful documentation.

Developers leave institutional knowledge vanishes and new hires spend weeks reading spaghetti code just to understand system dependencies and architectural patterns.

When teams try to write documentation everyone uses a different ad hoc format. Diagrams get outdated terminology is inconsistent and monorepo inter dependencies remain completely undocumented.

## The Solution

I built this skill to systematically generate comprehensive codebase knowledge bases.

It structures project documentation into clean architecture diagrams domain concept maps module dependency graphs and concise coding pattern summaries under 150 lines per pattern.

## How This Skill Solves It

* **Mermaid Architecture Visualizations:** Generates clean visual system and data flow charts that render natively on GitHub.
* **Domain Concept Glossaries:** Defines domain models and ubiquitous business language to eliminate developer confusion.
* **Monorepo Dependency Tracking:** Maps cross package dependencies and technology matrices across large workspaces.
* **State and Metadata Tracking:** Generates metadata files to monitor documentation currency and automate updates during CI.

## Quick Setup

Drop the skill folder directly into your agent skills directory:
```bash
~/.gemini/config/skills/codebase-knowledge-base
```
