# Executive Design System

Stop shipping AI-slop user interfaces. Equip your coding agents with Linear, Stripe Workbench, and Raycast-grade frontend standards.

---

## The Problem
When full-stack engineers and solo founders build with Cursor or Claude, the AI defaults to generic Tailwind templates, bloated purple gradients, bad spacing, and visual clutter.

## The Solution
Executive Design System injects high-taste design rules directly into your agent runtime:
1. **Three-Tier Information Architecture:** Action Center (Inbox), Activity Pulse, and The Vault.
2. **Mad Lib Rule Builders:** Replaces raw JSON and cron configurations with tokenized human sentences.
3. **Progressive Technical Disclosure:** Executive summaries by default with deep developer drawers only when requested.
4. **Motion Physics:** Lenis smooth scroll and subtle interaction states instead of jarring animations.
