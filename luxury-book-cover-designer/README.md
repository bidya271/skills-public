# Luxury Book Cover Designer

Produce publication-grade front and back book covers engineered for Amazon KDP, IngramSpark, and digital bookstores.

## The Problem
Standard AI cover generators bake low-resolution gibberish typography directly onto images and fail Amazon KDP trim and barcode margin requirements.

## The Solution
A decoupled two-stage publishing engine that pairs custom photorealistic fine-art Chiaroscuro illustrations with browser-rendered gold leaf typography and dark, compliant barcode zones.

## Quick Setup
Drop into your skills folder:
```bash
~/.gemini/config/skills/luxury-book-cover-designer
```
