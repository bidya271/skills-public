# Skills Portfolio by Bidya

Catalog of professional AI agent skills and autonomous execution frameworks architected and curated by Bidya.

Designed for Antigravity Claude Code Cursor OpenAI Codex and Gemini.

---

## Repository Architecture

```
skills/
├── README.md              # Master directory catalog and documentation
├── skill/                 # Full working skills with executable code and workflows (Protected)
└── skill_public/          # Public overviews detailing the real-world problem and high-level solution
```

* **`skill/`**: Detailed full working skill packages ready for execution or marketplace deployment. Contains complete instruction sets prompts workflows and scripts.
* **`skill_public/`**: Clean high-level summaries for prospective buyers and public users explaining what problems exist for developers and PMs in todays AI landscape and how each skill solves them without leaking proprietary prompts.
