# Skills Repository

Catalog of professional AI agent skills and autonomous execution frameworks authored and curated by Bidya.

Designed for Antigravity, Claude Code, Cursor, OpenAI Codex, and Gemini.

---

## 📂 Repository Architecture

As shown in our organizational diagram, this repository is split into two primary layers:

```
skills/
├── README.md              # Master directory catalog and documentation
├── skill/                 # Full working skills with executable code, schemas, and prompts (Protected)
└── skill_public/          # Public overviews detailing the real-world problem and high-level solution
```

* **`skill/`**: Detailed, full working skill packages ready for execution or marketplace deployment (Agensi, Gumroad, Antigravity). Contains complete instruction sets, prompts, workflows, and scripts.
* **`skill_public/`**: Clean, high-level summaries for prospective buyers and public users explaining what problems exist for developers/PMs in today's AI landscape and how each skill solves them without leaking proprietary prompts.
