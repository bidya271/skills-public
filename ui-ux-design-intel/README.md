## The Problem

AI coding assistants default to generic visually bland user interfaces.

Whether you ask Cursor or Claude to build a landing page dashboard or mobile app it defaults to the same uninspired gray cards blue buttons and generic typography.

Developers lack the design vocabulary to specify advanced aesthetics like brutalism glassmorphism or bento grids and the resulting code lacks responsive polish accessible color contrast and proper micro-interactions.

## The Solution

I created this skill to turn your coding agent into an expert visual designer and design system architect.

It equips your agent with a vast structured knowledge base of 50 distinct aesthetic styles curated color harmonies battle-tested font pairings and implementation patterns across modern frontend stacks.

## How This Skill Solves It

* **50 Curated Design Styles:** From minimal Swiss editorial and neo-brutalism to dark mode cyber aesthetics and clean bento grids.
* **Palette & Font Harmonies:** Instant access to 21 verified color schemes and 50 font pairings with accessible contrast ratios.
* **Stack Specific Implementation:** Tailors code outputs directly for modern component architectures.
* **UX Component Patterns:** Best practices for navigation sidebars action dialogs responsive tables and interactive dashboards.
