## The Problem

AI makes writing fast but thinking shallow.

Most PMs today use AI as a document generator. They feed raw prompts and get twenty page PRDs in seconds. Backlogs instantly fill up with unvalidated features that nobody asked for and nobody uses.

Speed without direction is just high speed waste. When AI acts like a passive yes person teams ship more code while solving fewer real customer problems.

## The Solution

PMs do not need another text generator. They need a strategic filter.

A good product tool should challenge weak assumptions before engineers write code. It should interrogate executive and sales requests to uncover the root friction. It should slice massive roadmaps into tiny testable increments and demand real user telemetry.

## How This Skill Solves It

Bidya PM turns your AI coding agent into an uncompromising product advisor.

* **Decodes Demand:** It interrogates incoming requests to find the real job to be done and prevents shiny feature distraction.
* **Maps Opportunities:** It links top level company goals directly to specific user friction points instead of arbitrary feature lists.
* **Slices Deliverables:** It breaks massive epics into thin vertical slices with clear acceptance rules and tracking events.
* **Validates AI Ideas:** It checks if machine learning features actually need a model or just simple software logic with fallback plans.
