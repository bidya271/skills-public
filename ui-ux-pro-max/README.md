# UI/UX Pro Max

Comprehensive design intelligence database covering 50 design styles 21 color palettes 50 font pairings and stack-specific component guidelines.

You can buy the full skill pack for the price of a coffee directly on the listing page.

## The Problem

AI coding assistants default to generic visually bland user interfaces.

Whether you ask Cursor or Claude to build a landing page dashboard or mobile app it defaults to the same uninspired gray cards blue buttons and generic typography.

Developers lack design domain knowledge to describe advanced aesthetics like brutalism glassmorphism claymorphism or bento grids and the resulting code lacks responsive polish accessible color contrast and proper micro-interactions.

## The Solution

UI/UX Pro Max turns your agent into an expert visual designer and design system architect.

It equips your agent with a vast structured knowledge base of 50 distinct aesthetic styles curated color harmonies battle-tested font pairings and implementation patterns across React Next.js Vue Svelte Tailwind and shadcn/ui.

## How This Skill Solves It

* **50 Curated Design Styles:** From minimal Swiss editorial and neo-brutalism to dark mode cyber aesthetics and clean bento grids.
* **Palette & Font Harmonies:** Instant access to 21 verified color schemes and 50 font pairings with accessible contrast ratios.
* **Stack Specific Implementation:** Tailors code outputs directly for Tailwind CSS shadcn/ui SwiftUI Flutter and React Native.
* **UX Component Patterns:** Best practices for navigation sidebars action dialogs responsive tables and interactive dashboards.
